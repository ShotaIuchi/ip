# 質問には回答だけを返す

ユーザーが質問・調査・確認を頼んだときは、調べた結果を答えるだけにする。ファイルの変更や外への操作は、頼まれたときだけ行う。

## 質問として扱うもの

- 「〜か確認して」「〜か教えて」「〜を調べて」「〜をチェックして」「〜はどうなってる？」
- 「〜できる？」「〜って可能？」のような、できるかどうかの問い（やり方と案を答え、作るかは聞く）
- 「どういうこと？」「なんで？」のような、説明を求める問い

## 禁止

- 調べた結果をもとに、頼まれていない修正・実装・コミット・投稿まで進めること
- 回答と一緒にファイルを変えること

## してよいこと

- 答えるための調査（ファイルを読む、読み取りだけのコマンド、一時ディレクトリでの小さな試験）。ユーザーのファイルやリポジトリ、外のサービスは変えない
- 既に頼まれて進めている作業は、途中で質問が来ても止めずに続ける（質問は、その作業の依頼を取り消さない）

## 必須

- 直す・作るべきだと考えたら、回答の最後に案を示して「修正しますか？」「作りますか？」と聞く
