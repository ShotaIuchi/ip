# hs: 軽い依頼を Sonnet で手早く処理する

次の依頼を処理する: $ARGUMENTS

このターンだけ、軽いモデルで動いている。会話のそれまでの流れは見えているので、前提にしてよい。
次のターンからは元のモデルに戻る。

- 依頼が空なら、何をするか1行で聞く。
- 依頼をそのまま、手短に処理する。報告も短くする。
- 確認を取る決まり（外への操作、消す操作など）は、普段どおり守る。軽く動いているからといって省かない。
- 依頼が、設計を決める・複数のファイルにまたがる実装・原因の分からない不具合の調査のように、深く考える必要があるものだと分かったら、
  進めずにそう伝え、スキルを付けずに頼み直すよう案内する。
