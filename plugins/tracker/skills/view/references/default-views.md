# 既定のビュー

プラグインに入っている既定のビューである。書き方と変え方（置き場所と読む順）は `view-format.md` に従う。
`自分の担当` を既定のビュー（引数なしの `/tracker:view` で使うもの）とする。

## 自分の担当

自分が担当している、終わっていないチケットを、状態ごとにまとめて見る。

- **対象**: 全部
- **条件**: 担当 に含む @自分 かつ 状態 != @完了
- **列**: キー、タイトル、状態、種類、ラベル、更新日、トラッカー
- **並び**: 更新日 降順
- **まとめ方**: 状態
- **出し方**: chat

## 進行中

担当にかかわらず、作業が進んでいるチケット（`@進行中` の意味は `view-format.md` の「条件の書き方」）を1つの表で見る。

- **対象**: 全部
- **条件**: 状態 = @進行中
- **列**: キー、タイトル、状態、担当、更新日、トラッカー
- **並び**: 状態 昇順、更新日 降順
- **まとめ方**: なし
- **出し方**: chat

## チケット詳細

キー・番号・URL を渡されたときに、そのチケット1件を見る。「見る」で取った本文・子・コメントを項目の後に添える。

- **対象**: 全部
- **条件**: キー = @引数
- **列**: キー、タイトル、状態、担当、種類、ラベル、更新日、URL、トラッカー
- **まとめ方**: 1件ずつ
- **出し方**: chat
