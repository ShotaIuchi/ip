# 既定のビュー

プラグインに入っている既定のビューである。書き方と変え方（置き場所と読む順）は `view-format.md` に従う。
どう見せるかはビューに書かず、出すときに選ぶフォーマット（`default-formats.md`・`display-format.md`）で決める。
`自分の担当` を既定のビュー（引数なしの `/tracker:view` で使うもの）とする。

## 自分の担当

自分が担当している、終わっていないチケットを見る。

- **対象**: 全部
- **条件**: 担当 に含む @自分 かつ 状態 != @完了
- **列**: キー、タイトル、状態、種類、ラベル、更新日、トラッカー
- **並び**: 更新日 降順

## 進行中

担当にかかわらず、作業が進んでいるチケット（`@進行中` の意味は `view-format.md` の「条件の書き方」）を見る。

- **対象**: 全部
- **条件**: 状態 = @進行中
- **列**: キー、タイトル、状態、担当、更新日、トラッカー
- **並び**: 状態 昇順、更新日 降順

## チケット詳細

キー・番号・URL を渡されたときに、そのチケット1件を見る。フォーマットはその群の `詳細` を使う（`../SKILL.md` の Step 3）。

- **対象**: 全部
- **条件**: キー = @引数
- **列**: キー、タイトル、状態、担当、種類、ラベル、更新日、URL、トラッカー
