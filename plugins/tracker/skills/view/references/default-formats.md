# 組み込みのフォーマット

プラグインに入っている組み込みのフォーマットである。書き方と変え方（置き場所と読む順）は `display-format.md` に従う。
選ぶリストでは、組み込みの分を群ごとにこの順で並べる（各群の `表` が先頭）。コンソールの各フォーマットには出力の見本を添える（値は例）。

## 表

1つの表で見る。コンソールの群の既定の形。

- **群**: コンソール
- **型**: 表
- **まとめ方**: なし

```markdown
| キー | タイトル | 状態 | 更新日 | トラッカー |
|---|---|---|---|---|
| #12 | ログインの不具合を直す | 進行中 | 2026-11-20 10:05 | アプリ |
```

## 状態ごとの表

状態ごとに表を分けて見る。

- **群**: コンソール
- **型**: 表
- **まとめ方**: 状態

```markdown
### 進行中
| キー | タイトル | 更新日 |
|---|---|---|
| #12 | ログインの不具合を直す | 2026-11-20 10:05 |
```

## 簡易一覧

1件を1行にして、短く見る。

- **群**: コンソール
- **型**: 簡易一覧
- **まとめ方**: なし

```markdown
- #12 ログインの不具合を直す — 進行中 — 2026-11-20 10:05
- <KEY>-3 検索を速くする — レビュー待ち — 2026-11-19 18:30
```

## 詳細

1件ずつ、本文・子・コメントまで見る。キー・番号・URL を渡されたときに使う。

- **群**: コンソール
- **型**: 詳細

```markdown
### #12 ログインの不具合を直す
- 状態: 進行中
- 担当: <人>
- 更新日: 2026-11-20 10:05

<本文> / 子: #13 画面の文言（完了） / コメント: <人>（2026-11-19）<本文>
```

## 表

取った時点の内容で、1つの表のページを作る。

- **群**: アーティファクト
- **型**: 表
- **まとめ方**: なし
- **更新**: しない
- **テンプレート**: templates/table.html

## カンバン

状態ごとの列のページを作り、開いたときと「更新」ボタンで取り直す。

- **群**: アーティファクト
- **型**: カンバン
- **更新**: 開いたとき
- **テンプレート**: templates/kanban.html

## 自動更新の表

1つの表のページを作り、60秒ごとに取り直す。

- **群**: アーティファクト
- **型**: 表
- **まとめ方**: なし
- **更新**: 60秒
- **テンプレート**: templates/table.html

## 詳細

取った時点の内容で、1件ずつ本文・子・コメントまで見せるページを作る。キー・番号・URL を渡されたときに使う。

- **群**: アーティファクト
- **型**: 詳細
- **更新**: しない
- **テンプレート**: templates/detail.html
