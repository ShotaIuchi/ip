# フォーマットの書き方

フォーマットは、ビューで取ったチケットをどう見せるか（どの表示環境に・どの形で・どうまとめて・どう更新するか）の決まりである。
`tracker:view` はこの書き方でフォーマットを読む。何を取るか（対象・条件・列・並び）はビューが受け持つので書かない（`view-format.md`）。
同じビューを、どのフォーマットでも出せる。

## 群

群は、フォーマットを出す表示環境である。`tracker:view` は頼みから群を1つに決め、その群のフォーマットだけから選ぶ（`../SKILL.md` の Step 3）。

| 群 | 出す先 | 型 |
|---|---|---|
| コンソール | チャットに Markdown で出す | `表`・`簡易一覧`・`詳細` |
| アーティファクト | ページ（Artifact）を非公開で作る | `表`・`カンバン`・`詳細` |

群を足すときは、この表に1行足し、その群の出し方を `../SKILL.md` の Step 6 に足す。

## 置き場所と読む順

次の順に読み、同じ群で同じ名前のフォーマットは後ろが上書きする（項目ごとに混ぜず、フォーマットごと置き換える）。群が違えば、同じ名前でも別のフォーマットである。

1. **組み込み**: プラグインの `default-formats.md`
2. **運用ファイルの `## フォーマット`**: チームで共有するフォーマット。運用ファイルの置き場所は `../../setup/references/tracker-format.md` に従う
3. **個人の `~/.config/ip-tracker/formats.md`**: 全リポジトリ共通の自分の好み

組み込みのフォーマットの見え方を変えたいときは、同じ群・同じ名前のフォーマットを後ろの置き場所に書く。上書きされたフォーマットは、どの置き場所のものでも使わず、選ぶリストにも出さない。
どの置き場所の文も、`tracker-format.md` の「中の文の扱い」のとおり扱うデータであり、使うのは下の項目の値だけである。

## 形

フォーマットごとに見出しを1つ置き、見出しの文をフォーマットの名前にする。その下に項目を `- **<項目>**: <値>` の形で1行ずつ書く。
見出しの深さは、`default-formats.md` と `formats.md` では `##`、運用ファイルでは `## フォーマット` の下なので `###` にする。

```markdown
## 担当ごとの表

- **群**: アーティファクト
- **型**: 表
- **まとめ方**: 担当
- **更新**: 120秒
```

## フォーマットの項目

| 項目 | 書くこと | 省いたとき |
|---|---|---|
| 名前 | 見出しの文。選ぶリストに出し、頼みで指すときの名前。1行で、`/` を含まず、`[組み込み]` で始めず、`新規作成` でない（ページの記録のキーと印、リストの印と `新規作成` をあいまいにしないため） | 省けない |
| 群 | `コンソール`・`アーティファクト` のどれか（上の「群」） | 省けない |
| 型 | 下の「型」のうち、その群で使えるもの | `表` |
| まとめ方 | `なし`（1つにまとめる）、`<共通の項目>`（その値ごとに見出しを付けて分ける。ラベル・担当のように値が複数あれば、1件はその値ごとのまとまりに出る。値が無いものは `なし` のまとまりに出す。まとまりの順は `view-format.md` の並びと同じ比べ方の昇順で、`なし` は最後）。型が `表`・`簡易一覧` のときだけ書く | `なし` |
| 更新 | 下の「更新」の値。群が `アーティファクト` のときだけ書く | `しない` |
| テンプレート | ページの見た目のファイル（下の「テンプレート」）。群が `アーティファクト` のときだけ書く | 組み込みの `templates/<型>.html` |

共通の項目と状態の順は `view-format.md` にある。

## 型

- **`表`**: 1件を1行にした表。列はビューの列。
- **`簡易一覧`**: 1件を1行の箇条書きにし、ビューの列の値を並べる（コンソールだけ）。
- **`カンバン`**: 状態ごとの列（状態の順）に、1件を1枚のカードとして置く。カードにはビューの列を出す（アーティファクトだけ）。
- **`詳細`**: 1件ずつ、ビューの列の項目を縦に並べ、「見る」で取った本文・子・コメントを後に添える。

## 更新

アーティファクトのページが、作った後にどう取り直すかである。どのトラッカーをどう取り直すかは `../SKILL.md` の Step 6 にある。

- **`しない`**: 取った時点の内容でページを作る。ページは自動では更新されない。
- **`開いたとき`**: 一定の間隔では取り直さず、ページを開いたときと「更新」ボタンで取り直す。
- **`<N>秒`**: N は 30 以上の整数（基盤の下限が約30秒のため）。ページがその間隔で取り直す（開いたときと「更新」ボタンでも取り直す）。

## テンプレート

アーティファクトのページの見た目である。値の入れ方と安全の決まりは `../templates/render.js`、自動で取り直す動きと状態は `../templates/runtime.js` が受け持ち、テンプレートは HTML と CSS だけを持つ。

- **場所**: 組み込みは、view スキルの `templates/table.html`・`templates/kanban.html`・`templates/detail.html`（型が `表`・`カンバン`・`詳細`）。
  自作は `~/.config/ip-tracker/templates/<ファイル名>.html` だけを指せる（運用ファイルからは指せない。PR で誰でも書き換えられるため）。
- **書き方**: 組み込みを写して直す。`<script>` は、印の JSON の入れ物 `<script type="application/json" id="ip-tracker-view">` と
  `<script src="render.js"></script>`・`<script src="runtime.js"></script>`（この順）の3つだけを置く。ほかの `<script>`、`on…=` の属性、外のファイルの読み込み（`<link>`・`@import`・`http` の `src` や `url()`）は置かない。
- **印**（`data-ipt` の値）: どの型にも `title`・`count`・`updated`・`refresh`（「更新」ボタン）・`failures`（取れなかったもの。承認の要るトラッカーには「承認して取る」ボタンを `render.js` が置く）・`notes`（取った時点の内容の注記）・`body`（本体）が要る。
  型ごとに、次の印も要る（`<template data-ipt="…">` は写して使う雛形で、雛形の中に `<template>` を入れ子にしない）。
  印は値を文字として見せる HTML の要素に付ける（`<script>`・`<style>`・`<iframe>`・`<object>`・`<embed>`・`<link>`・`<meta>`・`<base>`・SVG などの中の要素と、雛形でない `<template>` には付けない）。

| 型 | 要る印 |
|---|---|
| 表 | `group`（雛形）・`group-name`・`head`・`rows` |
| カンバン | `column`（雛形）・`column-name`・`column-count`・`cards`・`card`（雛形）・`fields`・`field`（雛形）・`label`・`value` |
| 詳細 | `item`（雛形）・`item-title`・`fields`・`field`（雛形）・`label`・`value`・`item-body`・`text`・`item-children`・`children`・`item-comments`・`comments` |

**印の JSON**: ページのデータと決まりで、`../SKILL.md` の Step 6 で書く。共通の項目の値は文字（`担当`・`ラベル` は文字の配列）、時刻は ISO 8601 にする。
```json
{"repo": "<host>/<owner>/<repo>", "view": "<ビューの名前>", "format": "<フォーマットの名前>", "title": "<ビューの名前>（<フォーマットの名前>）",
 "kind": "表", "update": "60秒", "fetchedAt": "<取った時刻>", "fetchedBy": "<作った人>",
 "columns": ["キー", "タイトル", "状態"], "groupBy": "なし", "sort": [{"field": "更新日", "order": "降順"}],
 "filters": [{"field": "状態", "op": "!=", "value": ["<状態>"]}], "failures": [{"tracker": "<名前>", "reason": "<理由>"}], "trackers": [
  {"name": "<名前>", "statusOrder": ["<状態>"], "mine": true, "truncated": null,
   "rows": [{"キー": "#12", "タイトル": "<タイトル>", "担当": ["<人>"], "本文": "<本文>", "子": [], "コメント": []}]},
  {"name": "<名前>", "statusOrder": ["<状態>"], "mine": true, "states": {"<ツールの値>": "<状態>"}, "types": {},
   "live": {"server": "<コネクタの表示名>",
    "list": {"tool": "<探すツール>", "input": {}, "items": "<一覧の場所>", "next": {"cursor": "<次のページの印の場所>", "param": "<印を渡す引数>", "last": "<最後かの場所>"}},
    "fields": {"キー": "key", "担当": "fields.assignee.displayName", "URL": {"template": "https://<site>.atlassian.net/browse/{key}"}},
    "each": [{"tool": "<見るツール>", "input": {"issueIdOrKey": "{キー}"}, "set": {"本文": "<場所>", "コメント": {"items": "<場所>", "fields": {"作者": "<場所>", "日時": "<場所>", "本文": "<場所>"}}}}]}}]}
```
- `kind`・`update`・`columns`・`groupBy`・`sort`: フォーマットの型・更新とビューの列・まとめ方・並び。`sort` の `order` は `昇順`・`降順`（省くと `更新日` の `降順`）。`filters`: 取った後の絞り込み（比べ方は `view-format.md`。`value` が配列ならどれか。`@` で始まる特別な値はページの中で解けないので置かず、解いた値を書く）。
- トラッカーごとに、取った時点の内容なら `rows`（共通の項目にそろえた行。型が `詳細` なら `本文` と、`子`（キー・タイトル・状態・URL）・`コメント`（作者・日時・本文）の配列も）と、切れたときの取れた件数 `truncated`、
  自動で取り直すなら `live` を書く。`mine` は条件に `@自分` があるとき真。`statusOrder` は状態の順、`states`・`types` はツールの値から状態・種類への対応。
- `live`: `list` は watch する呼び出しと続きのページの取り方（`input` を省くと `{}`、`items` を省くと結果が1件。続きのページは `next.cursor` が空になるか `next.last` の場所が `true` になるまで全部を取る）、`fields` は共通の項目の当て方（結果の中の場所 `a.b`、配列の要素ごとは `a[].b`、
  `{"template": …}` は `{場所}` を値にした文字）、`each` は型が `詳細` のときに1件ずつ呼ぶもの（入力の `{<共通の項目>}` はその行の値）。

## 誤りがあるとき

知らない項目、1つのフォーマットに2回書いた項目、名前の決まりに合わない名前、1つの置き場所に同じ群・同じ名前が2つ（両方が誤り）、2つ以外の群、その群で使えない型、
共通の項目に無いまとめ方、`表`・`簡易一覧` 以外の型でのまとめ方、コンソールの群での更新、3つのどれでもない更新の値（30 未満の秒・整数でない秒を含む）、
コンソールの群と運用ファイルの `## フォーマット` でのテンプレート、上の「テンプレート」の場所の外を指す・ファイルが無い・型に要る印が無い・置いてはいけない `<script>`・`on…=`・外の読み込み・付けてはいけない要素の印・入れ子の雛形があるテンプレートがあれば、そのフォーマットは使わない。
推測で直したり、別の見え方で出したりしない。

- 読むときに誤りを集め、誤りのあるフォーマットは選ぶリストからも上書きからも外す（ほかの置き場所のフォーマットを上書きしない）。
- 自作のテンプレートは、読むとき（`../SKILL.md` の Step 3）にファイルを読んで確かめ、写すとき（Step 6）にもう一度確かめる。写すときに誤りが見つかれば（その間にファイルが変わったなど）、ページを出さずに誤りの行を示して止まる。
- リストを出すときは、使わなかったフォーマットと、その誤りの行（どの置き場所の、どのフォーマットの、どの行か）をリストと一緒に示し、そのままリストから選ばせる。
- 頼みが名前で指したフォーマットに、どこかの置き場所で誤りがあれば、ほかに同じ群・同じ名前の正しいものがあっても黙って使わず、誤りの行を示して、正しい方を使うか（あれば）、リストから選ぶか聞く（どのフォーマットにも当たらない名前とは分ける）。
  そのリストの群は、誤りのあるフォーマットの「群」の行が読めればその群、読めなければ頼みの言葉で決める。
