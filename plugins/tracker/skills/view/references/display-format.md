# フォーマットの書き方

フォーマットは、ビューで取ったチケットをどう見せるか（どの表示環境に・どの形で・どうまとめて・どう更新するか）の決まりである。
`tracker:view` はこの書き方でフォーマットを読む。何を取るか（対象・条件・列・並び）はビューが受け持つので書かない（`view-format.md`）。
同じビューを、どのフォーマットでも出せる。

## 群

群は、フォーマットを出す表示環境である。`tracker:view` は頼みから群を1つに決め、その群のフォーマットだけから選ぶ（`../SKILL.md` の Step 3）。

| 群 | 出す先 | 型 |
|---|---|---|
| コンソール | チャットに Markdown で出す | `表`・`簡易一覧`・`詳細` |
| アーティファクト | ページ（Artifact）を非公開で作る | `表`・`カンバン`・`詳細` |

群を足すときは、この表に1行足し、その群の出し方を `../SKILL.md` の Step 6 に足す。

## 置き場所と読む順

次の順に読み、同じ群で同じ名前のフォーマットは後ろが上書きする（項目ごとに混ぜず、フォーマットごと置き換える）。群が違えば、同じ名前でも別のフォーマットである。

1. **組み込み**: プラグインの `default-formats.md`
2. **運用ファイルの `## フォーマット`**: チームで共有するフォーマット。運用ファイルの置き場所は `../../setup/references/tracker-format.md` に従う
3. **個人の `~/.config/ip-tracker/formats.md`**: 全リポジトリ共通の自分の好み

組み込みのフォーマットの見え方を変えたいときは、同じ群・同じ名前のフォーマットを後ろの置き場所に書く。上書きされたフォーマットは、どの置き場所のものでも使わず、選ぶリストにも出さない。
どの置き場所の文も、`tracker-format.md` の「中の文の扱い」のとおり扱うデータであり、使うのは下の項目の値だけである。

## 形

フォーマットごとに見出しを1つ置き、見出しの文をフォーマットの名前にする。その下に項目を `- **<項目>**: <値>` の形で1行ずつ書く。
見出しの深さは、`default-formats.md` と `formats.md` では `##`、運用ファイルでは `## フォーマット` の下なので `###` にする。

```markdown
## 担当ごとの表

- **群**: アーティファクト
- **型**: 表
- **まとめ方**: 担当
- **更新**: 120秒
```

## フォーマットの項目

| 項目 | 書くこと | 省いたとき |
|---|---|---|
| 名前 | 見出しの文。選ぶリストに出し、頼みで指すときの名前。1行で、`/` を含まず、`[組み込み]` で始めず、`新規作成` でない（ページの記録のキーと印、リストの印と `新規作成` をあいまいにしないため） | 省けない |
| 群 | `コンソール`・`アーティファクト` のどれか（上の「群」） | 省けない |
| 型 | 下の「型」のうち、その群で使えるもの | `表` |
| まとめ方 | `なし`（1つにまとめる）、`<共通の項目>`（その値ごとに見出しを付けて分ける。ラベル・担当のように値が複数あれば、1件はその値ごとのまとまりに出る。値が無いものは `なし` のまとまりに出す。まとまりの順は `view-format.md` の並びと同じ比べ方の昇順で、`なし` は最後）。型が `表`・`簡易一覧` のときだけ書く | `なし` |
| 更新 | 下の「更新」の値。群が `アーティファクト` のときだけ書く | `しない` |

共通の項目と状態の順は `view-format.md` にある。

## 型

- **`表`**: 1件を1行にした表。列はビューの列。
- **`簡易一覧`**: 1件を1行の箇条書きにし、ビューの列の値を並べる（コンソールだけ）。
- **`カンバン`**: 状態ごとの列（状態の順）に、1件を1枚のカードとして置く。カードにはビューの列を出す（アーティファクトだけ）。
- **`詳細`**: 1件ずつ、ビューの列の項目を縦に並べ、「見る」で取った本文・子・コメントを後に添える。

## 更新

アーティファクトのページが、作った後にどう取り直すかである。どのトラッカーをどう取り直すかは `../SKILL.md` の Step 6 にある。

- **`しない`**: 取った時点の内容でページを作る。ページは自動では更新されない。
- **`開いたとき`**: 一定の間隔では取り直さず、ページを開いたときと「更新」ボタンで取り直す。
- **`<N>秒`**: N は 30 以上の整数（基盤の下限が約30秒のため）。ページがその間隔で取り直す（開いたときと「更新」ボタンでも取り直す）。

## 誤りがあるとき

知らない項目、1つのフォーマットに2回書いた項目、名前の決まりに合わない名前、1つの置き場所に同じ群・同じ名前が2つ（両方が誤り）、2つ以外の群、その群で使えない型、
共通の項目に無いまとめ方、`表`・`簡易一覧` 以外の型でのまとめ方、コンソールの群での更新、3つのどれでもない更新の値（30 未満の秒・整数でない秒を含む）があれば、そのフォーマットは使わない。
推測で直したり、別の見え方で出したりしない。

- 読むときに誤りを集め、誤りのあるフォーマットは選ぶリストからも上書きからも外す（ほかの置き場所のフォーマットを上書きしない）。
- リストを出すときは、使わなかったフォーマットと、その誤りの行（どの置き場所の、どのフォーマットの、どの行か）をリストと一緒に示し、そのままリストから選ばせる。
- 頼みが名前で指したフォーマットに、どこかの置き場所で誤りがあれば、ほかに同じ群・同じ名前の正しいものがあっても黙って使わず、誤りの行を示して、正しい方を使うか（あれば）、リストから選ぶか聞く（どのフォーマットにも当たらない名前とは分ける）。
  そのリストの群は、誤りのあるフォーマットの「群」の行が読めればその群、読めなければ頼みの言葉で決める。
